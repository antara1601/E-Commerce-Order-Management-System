Database Structure

Six main tables in the project

👥 Customers

  • Customer_ID PK
  • Customer details

📦 Products

  • Product_ID PK
  • Product details
  • Price information

🏷️ Inventory

  • Inventory_ID PK
  • Product_ID FK
  • Stock quantity

🛒 Orders

  • Order_ID PK
  • Customer_ID FK
  • Order date and status

🧾 Order_Items

  • Order item details
  • Order_ID FK
  • Product_ID FK
  • Quantity and price

🔄 Order_Status_History

  • Status history details
  • Order_ID FK
  • Status and update time

PK = Primary Key • FK = Foreign Key. Refer to the SQL script for the exact column definitions and relationships.

SQL Demo

Example query to explore orders and customer details

SELECT
    o.Order_ID,
    o.Customer_ID,
    o.Order_Date,
    o.Status
FROM Orders AS o
ORDER BY o.Order_Date DESC;

This is an illustrative query. Check the actual column names in your SQL script before running it.
