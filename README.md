# E-Commerce Order Management System using MySQL

## 📌 Project Overview
The E-Commerce Order Management System is a database project developed using MySQL to manage customers, products, inventory, orders, and order status history.

## 🎯 Objectives
- Store and manage customer and product details.
- Manage customer orders and order items.
- Track inventory and stock availability.
- Maintain order status history.
- Generate useful reports using SQL queries.

## 🛠️ Technologies Used
- MySQL
- MySQL Workbench
- SQL

## ✨ Key Features
- Relational database design using primary keys and foreign keys.
- Inventory and order management.
- Triggers for stock updates and order status tracking.
- Stored procedures for order-related operations.
- Views for order details and inventory status.
- SQL queries for sales and inventory reports.

## 📂 Project Files
- `ecommerce_order_management.sql` — SQL script containing the database implementation.

This project helped me understand relational database design, SQL queries, triggers, stored procedures, views, and inventory management.
